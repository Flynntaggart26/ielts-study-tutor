# Writing Checklist (use before submitting any Task 1/2)

## Task 2
- [ ] 250+ words counted?
- [ ] Position clear in intro + conclusion (same side)?
- [ ] All parts answered (discuss both + give opinion if asked)?
- [ ] 2 body paragraphs, each: topic sentence → explain → example?
- [ ] 5+ collocations (underline them)?
- [ ] 60% complex sentences? 2x relative + 1x conditional?
- [ ] Articles checked (a/the)? SVA checked? Prepositions?
- [ ] No memorized phrases? No new idea in conclusion?
- [ ] 32-38 min timed?

## Task 1 Academic
- [ ] 150+ words? Overview with 2-3 trends, no numbers?
- [ ] Data grouped + compared (while/whereas/accounted for)?
- [ ] Tense correct (past for past years)?
- [ ] Paraphrased intro (no copy)?

If any box unchecked → fix before AI/tutor correction.
