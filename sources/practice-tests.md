# Practice Tests — Where & How

## Ranked List

1. **Cambridge IELTS 15-19 (paper or PDF + audio)** — Gold. Do newest first.
2. **British Council / IDP free computer mocks** — Book a free familiarisation test at your test centre.
3. **Road to IELTS (9 mocks)** — Best screen UI for CBT.
4. **Official Practice Materials Vol 1-2** — Includes examiner model answers.
5. **IELTS Online Tests / IELTS Mentor** — Extra volume only.

## How to Take a Mock (Protocol)

- Timed, no pause, same order: Listening (30m) → Reading (60m) → Writing (60m).
- Listening: use headphones, answer sheet transfer time (paper: 10 min, CBT: 2 min).
- Reading: no extra time. 20 min per passage max — move on.
- Writing: Task 1 (20 min) + Task 2 (40 min). Word count: 150+/250+ strictly.
- Speaking: separate day, record, with timer (11-14 min).

## Scoring

- Listening/Reading: raw → band table (varies per test, use book's table).
- Writing/Speaking: self-score with `templates/writing-checklist.md` + `templates/speaking-self-evaluation.md`, then AI/tutor correction.
- Log every error in `templates/study-tracker.csv` with reason: vocab / grammar / time / trick.

## Schedule

- B1-B2: 1 mock / 2 weeks
- B2-C1: 1 mock / week
- Last 2 weeks: 2 mocks / week, review day after each

Never take a mock without reviewing it fully the next day. Unreviewed mocks waste time.
