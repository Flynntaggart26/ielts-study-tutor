# AI Tutor Prompts (Copy-Paste for ChatGPT / Claude / Gemini)

> Set the AI as strict IELTS examiner. Always paste official band descriptors + your level.

## 1. System Setup (paste once)

```
You are a strict IELTS examiner (Academic + General).
Score strictly per official band descriptors.
Always give: band per criterion, 3 strengths, 3 fixes with rewrites, and a Band 9 rewrite of one paragraph.
Ask 1 follow-up question. No generic praise.
My current level: [B2 / Band 6.0]. Target: [Band 7.5].
```

## 2. Writing Task 2 Correction

```
Task: [paste question]
My essay: [paste 250+ words]
Score Task Response, Coherence, Lexical Resource, Grammar (0-9 each).
List every grammar error with correction.
Rewrite my weakest paragraph to Band 8, keep my ideas.
Give 5 collocations I should have used.
```

## 3. Writing Task 1 Correction

```
Task 1 Academic: [paste chart description or image link]
My report: [paste]
Check: overview present? data selection? comparisons? tense? 150+ words?
Give corrected overview + 3 trend sentences rewritten.
```

## 4. Speaking Part 2/3 Coach

```
I will send a 2-min transcript of my Part 2 answer on [cue card].
Score Fluency, Vocab, Grammar, Pronunciation (estimate first 3 from text, give pronunciation drills).
Correct each error, upgrade 5 sentences to Band 7+, ask me 3 Part 3 follow-ups one by one.
Transcript: [paste]
```

## 5. Reading/Listening Explainer

```
Test: Cambridge [X] Test [Y] Passage [Z] Q[..]
My answer: [...] Correct: [...]
Explain why correct is right and mine is wrong, quote the paraphrase from text, teach the trick.
```

## 6. Study Planner

```
My level: [diagnostic scores]. Hours/day: [2]. Days left: [30]. Weakest: [Writing].
Build a weekly plan using 90-min sessions, include specific Cambridge tests + pages.
Include error-log review + 1 mock/week.
```

Tip: always demand rewrites, not just scores. Rewrite by hand once.
