# How to Study IELTS — The Core Tutor Method

> Use this whether you study alone, with AI, or with a human tutor. Same loop.

## The Loop (90-min session)

```
0-10  Warm-up: Anki review + shadow 2 min audio
10-25 Input: 1 strategy lesson (e.g. T/F/NG) + model answer analysis
25-70 Deliberate practice: timed task (1 Reading passage / 1 essay / 1 cue card)
70-85 Feedback: error log + correction (checklist → AI/tutor)
85-90 Plan: write tomorrow's 3 tasks in tracker
```

## Weekly Rhythm (10-12h for working adults)

| Day | Focus (90 min) |
|-----|----------------|
| Mon | Listening + Vocab |
| Tue | Writing Task 2 |
| Wed | Reading + Grammar |
| Thu | Speaking (record) |
| Fri | Writing Task 1 + correction rewrite |
| Sat | Mock (alternate weeks) + review |
| Sun | Rest or light Anki + podcast |

Double to 20h by adding 1h Anki/podcast daily.

## Rules That Matter

1. **Feedback within 24h.** Uncorrected writing/speaking doesn't improve. Use AI prompts daily, human 1x/week.
2. **Error log > hours.** After each session log: what, why, fix. Review weekly patterns.
3. **One weakness at a time.** If articles kill Writing, fix only articles for 7 days.
4. **Timed from Week 2.** Untimed practice after Week 2 creates false confidence.
5. **No new sources in last 10 days.** Only Cambridge mocks + your error log.

## Self-Study vs AI Tutor vs Human Tutor

| Mode | Best For | Cadence |
|------|----------|---------|
| Self | Disciplined B2+ | Daily + weekly mock |
| AI (ChatGPT/Claude) | Instant Writing/Speaking feedback | Daily — use `ai-tutor-prompts.md` |
| Human | Speaking interaction, motivation, Band 7.5+ polish | 1-2x/week — use `tutor-framework.md` |

Combine: AI daily + human weekly = fastest progress per cost.

## When Are You Ready?

Book when: 3 consecutive timed mocks hit target, Writing corrected to target twice, Speaking self-evaluation 7+ on 5 recordings.
