# Common Mistakes That Cap Band 6.0

## Writing
1. No clear position (Task 2) / no overview (Task 1). → Fix with 4-paragraph template.
2. Memorized phrases ("In contemporary era...", "Every coin has two sides"). Examiners penalize. Use natural hedging.
3. Listing data without comparison (Task 1). Group + compare.
4. Underlength (Task 1 <150, Task 2 <250). Count every time in practice.
5. Articles/prepositions every sentence. Proofread last 3 min only for these.

## Speaking
1. One-sentence Part 1 answers. → Answer + reason + example.
2. Reading notes in Part 2. → Keywords only, keep eye contact (or camera).
3. Silence >3 sec. → Bridge phrases.
4. Simple sentences in Part 3. → Force 1 conditional + 1 complex sentence per answer.

## Listening/Reading
1. Ignoring word limits (NO MORE THAN TWO WORDS → "the big city" = 3, wrong).
2. Over-inferring NG (if not stated, it's NG — don't use logic).
3. Spending 5 min on 1 Q. Guess, mark, move.
4. Bad transfer spelling/plurals. Copy exactly as heard.

Check this list before every mock.
