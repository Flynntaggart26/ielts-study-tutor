# Contributing

Thanks for improving IELTS Study Tutor!

## How to Contribute
1. Check open issues — broken links, outdated sources, missing plans.
2. Fork → branch (`add/source-xyz` or `fix/reading-typo`) → PR.
3. For new sources: must include — name, URL, cost, level, why it's better than existing Tier equivalent, Academic/General label.
4. For study content: keep sessions 60-90 min, include timed practice + feedback step, no copyrighted test content pasted verbatim.

## Quality Bar
- Links tested (200 OK, 2026).
- No "guaranteed Band 8" spam, no referral spam, no full Cambridge PDFs (link only, respect copyright).
- Professional tone, actionable steps, checklists over theory.

## PR Template
See `.github/PULL_REQUEST_TEMPLATE.md`. Small PRs merge faster.
