# Writing Task 1 Academic — Reports (150+ words, 20 min)

## Task Types
Line/bar/pie/table, process diagram, map (changes), mixed (2 charts).

## Band 7 Structure (4 paragraphs)
1. **Paraphrase intro** (1-2 sentences, no copy).
2. **Overview** (2-3 key trends, no data — this decides Band 6 vs 7).
3. **Detail 1** (group logically + data).
4. **Detail 2** (compare, not list every number).

## Scoring Rules
- Task Achievement: overview + data selection + 150+ words.
- Cohesion: grouping + comparatives (while/whereas/compared to) + sequencing for processes.
- Vocab: trend language (surged, plummeted, fluctuated, remained stable), approximation (around, roughly, accounted for).
- Grammar: tense control (past for past years, present for process), passive for processes, articles.

## Common Band 5-6 Mistakes
- No overview or overview with numbers.
- Listing every data point, no comparison.
- Copying prompt, under 150 words, wrong tense.
