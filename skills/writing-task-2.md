# Writing Task 2 — Essay (250+ words, 40 min, 2x weight)

## Question Types
Opinion (agree/disagree), Discussion (both views + opinion), Problem/Solution, Advantages/Disadvantages, Two-part.

## Band 7+ Structure (4-5 paragraphs)
1. **Intro:** paraphrase + thesis (clear position).
2. **Body 1:** Topic sentence → explain → example → link.
3. **Body 2:** Same (counter-view + rebuttal for discussion).
4. **Conclusion:** restate position, no new ideas.

Plan 5 min → Write 32 min → Check 3 min.

## What Examiners Reward
- **Task Response:** answer all parts, clear position throughout, developed ideas with examples.
- **Cohesion:** paragraphing, linkers used naturally (not every sentence "Moreover").
- **Lexical Resource:** less common collocations (environmental degradation, economic disparity), correct word formation, no memorized phrases.
- **Grammar:** mix simple + complex (relative clauses, conditionals, passive), 70%+ error-free sentences for Band 7.

## Study Loop
1. Brainstorm 5 ideas in 3 min (IELTS Simon technique).
2. Write timed, count words.
3. Self-edit with checklist → Write & Improve → AI prompt (`tutor/ai-tutor-prompts.md`) → rewrite 1 paragraph.
4. Save good sentences to Anki.

3 essays/week minimum. Quality + correction > quantity.
